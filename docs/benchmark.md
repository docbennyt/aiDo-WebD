# Benchmark plan (not results)

Compare conventional prompting and WebD-assisted development for at least 30 matched tasks using equivalent source revisions, model/version, acceptance criteria and environment. Counterbalance order or use independent participants. Include CTA responsiveness, hero alignment, typography, card spacing, navigation overflow, component state, accessibility, shared components, design tokens and pricing layouts. Record setup/review/rework as part of elapsed time, correction turns, first-pass acceptance, observable token counts (otherwise unknown), files changed, unnecessary code churn, functional and visual regressions. Publish median and spread with failures and limitations, not only favorable examples. The 30% median time reduction is a hypothesis, not evidence. Get consent and sanitize any public artifact.

Record each task in CSV with columns: task_id,workflow,model,base_revision,elapsed_seconds,correction_turns,first_pass,observable_tokens,files_changed,visual_regressions,functional_regressions,accepted,notes. Use local fixtures first, then authorized aiDo previews.
